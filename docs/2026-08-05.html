1「想像してから動く」ロボットの弱点

ロボットに「次に何が起きるか」を考えさせてから動かす、というアプローチが近年広がっている。まず現在の映像と指示から未来の映像や状態を世界モデル環境の変化を予測し、未来の状態を推定するAIモデルで“想像”し、その想像をもとに行動を決める。人間が手を伸ばす前に頭の中でシミュレーションするのに近い発想だ。だが、この「想像」の計算コストが高く、ロボットの反応を遅くしてしまうという問題があった。今日紹介する論文は、想像する計算そのものを丸ごと折りたたんで、動くたびに想像せずに済ませてしまうという逆転の発想を提案する。

世界モデルの「未来を生成する力」は、未来を実際に描かなくても、現在の表現の中に折りたたんで使い回せる。

2背景：なぜロボットは動く前に「想像」するのか

World Action Model という枠組み

近年注目されるVLAモデルVision-Language-Action: 視覚と言語からロボットの行動を出力するモデルの発展形として、行動生成と未来予測を組み合わせた World Action Model という枠組みが登場している。カメラ映像と言語指示から行動をいきなり出すのではなく、「この行動をとったら次にどんな映像・状態になるか」をまず予測（生成）し、その予測を手がかりに行動を洗練させる仕組みだ。

ところがこの「想像」は、多くの場合、拡散モデルのようなノイズ除去崩れた情報から元の綺麗な状態を少しずつ復元していく処理を何ステップも繰り返して未来の映像や潜在状態を生成する、重い計算になる。ロボットが1回行動を決めるたびにこの重い生成過程を回すと、指示を受けてから行動を出力するまでの遅延（行動レイテンシ指示を受けてから実際に行動を出力するまでの遅延時間）が伸びてしまい、素早い反応が要求される実世界のタスクでは致命的になりうる。

3Enfold の発想：想像の「計算」だけを持ち帰る

著者らは、世界モデルが本当に有用なのは「生成された未来そのもの」ではなく「未来を組み立てていく過程で使われた計算」だと主張する。生成器がノイズだらけの未来を少しずつ整った軌道に直していく途中、その内部状態には、物体がどこにあり周囲とどう相互作用するかという情報が、抽象度の異なる複数のレベルで自然に整理されている。この「整理する力」こそが、使い回せる本当の資産だという発想だ。

学習時と推論時で「想像」の有無が変わる

学習：生成器の「頭の中」をエンコーダに教え込む

Enfold は、現在の映像と言語指示だけを受け取る軽量なエンコーダを新たに用意する。学習中は、実際に起きた未来の観測を世界モデルに読み込ませ、生成器が内部で作る複数レベルの状態を“正解”として、エンコーダの出力がそれに近づくよう蒸留大きく賢いモデルの振る舞いを、小さく速いモデルに学ばせる手法する（①②）。ここで重要なのはstop-gradient片方のネットワークには学習の勾配を伝えない工夫で、行動を当てるタスクの学習信号がこのエンコーダの中身を無理やり歪めてしまわないよう設計されている。

推論、つまり実際にロボットを動かす時には、世界モデルの生成器はもう呼び出さない（③）。現在の映像と指示をエンコーダに通すだけで、生成器を回したのと同じような「未来を織り込んだ」表現が一瞬で手に入り、それを行動予測ヘッドに渡すだけでよい。

5新規性・なぜ重要か

世界モデルは「未来を実際に描く生成器」としてだけでなく、「現在の表現に折りたたんで使う予測の源」として捉え直せる。

これまでの多くの研究は、世界モデルの生成物（映像や潜在状態）をどう賢く使うかに注目してきた。Enfold は視点を変え、生成の「過程」こそが再利用可能な知識だと捉え直した点に新規性がある。生成モデル・蒸留・自己教師あり学習といった複数の技術領域をまたいだ発想であり、推論効率と性能の両立という実務上の課題に対して、シンプルながら筋の通った解決策を示している。

実世界のロボットは、シミュレーションの中とは違い、待ってくれない。人や物が動き続ける環境で、行動を決めるまでに何百ミリ秒もかかっていては、せっかく賢い判断ができても間に合わない。強力だが重い世界モデルの恩恵を、軽くて速いモデルにも行き渡らせる、という今回の方向性は、精度と速度のどちらかを諦めがちだった実用ロボティクスに対して、両立への現実的な道筋を示すものだと言える。

6意義と限界

限界 1

学習時には依然として世界モデル（生成器）を動かして正解データを作る必要があり、計算コストは消えたのではなく訓練フェーズに移されている。

限界 2

検証は LIBERO・RoboTwin2.0・実機タスクの範囲にとどまっており、より多様で長期的な実世界タスクでの汎化性能は今後の検証課題として残る。

限界 3

どのような世界モデル・どのレベルの内部状態を選べば効果的に折りたためるのか、その設計指針はまだ体系化されていない。
