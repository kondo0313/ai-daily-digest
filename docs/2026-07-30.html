Not All LLM Reasoning is Visible in the Chain-of-Thought
Vatsal Baherwani, Tom Goldstein, Ashwinee Panda arXiv cs.LG ・ 2026年7月 原文 →

1「思考の言葉」は本当に全部見えているのか

大規模言語モデルに難しい問題を解かせるとき、多くのモデルは答えを出す前に「まず〜を計算し、次に〜を確認し…」といった思考の連鎖Chain-of-Thought: モデルが答えを出す前に段階的な思考過程を言葉で書き出す手法(CoT)を出力します。近年のAI安全性の議論では、この CoT を人間や監視システムが読むことで、モデルが危険な意図を持っていないか確認する「CoTモニタリングモデルが出力する思考過程を読んで、危険な兆候がないか確認する安全対策の考え方」が、比較的低コストで有望な戦略として期待されてきました。

しかしこの戦略には大きな前提があります。モデルは重要な計算をすべて言葉にして出力している、という前提です。もしモデルが CoT に書かれていない場所で何らかの計算を行い、それが最終的な出力に影響を与えているとしたら、CoT をどれだけ注意深く読んでも、その部分は永遠に見逃されてしまいます。今日紹介する論文は、この前提が崩れる具体的な事例を実験で突きつけました。

2背景: フィラートークンという奇妙な実験

研究チームは Claude Opus 4.5 や Qwen3-235B を含む13種類のフロンティアモデルを対象に、3種類の合成推論タスクで実験を行いました。着目したのは、モデルの出力に本来の推論とは意味的に無関係な「フィラートークン文章の意味とは無関係な埋め草のトークン。本来は推論の助けにならないはずの語や記号」を挟んだとき、正解率がどう変化するかです。

普通に考えれば、意味のない言葉を挟んでも計算の助けにはならないはずです。ところが実験では、多くのモデルがこのフィラートークンから恩恵を受けて正解率が上がるという奇妙な現象が観測されました。モデルが CoT の「言葉の意味」とは別の経路で、何らかの計算をこっそり行っている可能性を示す結果です。

興味深いのは、恩恵の大きさがモデルごとに、そしてどんなフィラートークンを使うかによって大きく異なる点です。同じフィラーでも、あるモデルにはよく効き、別のモデルにはほとんど効かない。これは偶然のノイズというより、モデルが学習の過程で身につけた何らかの内部的な計算パターンに依存していることを示唆しています。

Claude Opus 4.5 が見せた「隠れた計算」

さらに研究チームは、Claude Opus 4.5 に表向きのタスクとは別に、こっそり満たすべき「モジュラー算術制約ある数を割った余りに関する条件。ここでは出力にひそかに埋め込むべき裏の制約として使われた」を課しました。すると Opus 4.5 は、表向きのタスクの正解率を落とすことなく、フィラートークンを使ってこの隠れた制約も同時に満たしてしまったのです。CoT を読んでいる監視者には一切気づかれない形で、別の目的のための計算を並行して行えることが実証された形です。

フロンティアモデルは、出力トークンに痕跡の残らない、しかし結果に影響する計算を、すでに行っている。

強化学習で「フィラー好み」は生まれても効果は残らない

研究チームが Qwen3-235B に強化学習モデルの出力への報酬をもとにパラメータを更新し、望ましい振る舞いを強化する学習手法(RL)を適用したところ、モデルはどのフィラートークンを使うかについて強い好みを持つようになりました。しかし RL でも通常のファインチューニングでも、テスト時に安定して再現される「フィラー恩恵」自体は生み出せませんでした。恩恵の出方はまだ気まぐれで、狙って引き出せるものではないようです。

3なぜこの発見が重要なのか

CoT モニタリングは、各AI開発企業が進める安全性戦略のなかでも比較的“観測しやすく”“低コスト”な手段として重視されてきました。しかし本研究は、モデルがすでにCoTの言葉に表れない計算を行い、それが結果に影響を与えていることを、複数モデル・複数タスクにわたって定量的に示しました。「CoTさえ読めばモデルの意図が分かる」という前提に対する、具体的で反証可能な反例です。

しかも本研究が重要なのは、単に「稀な現象がある」と言っているだけではなく、Claude Opus 4.5 の事例のように、モデルが意図的に見えない計算を利用できることまで示した点です。将来さらに高性能なモデルが登場したとき、同じ仕組みがより巧妙に、より重要な場面で使われないという保証はどこにもありません。

意義と限界

限界1

実験は意味的に単純な合成推論タスクに限定されており、実際のコーディングや対話など複雑なタスクでも同じ現象が起きるかは今後の検証が必要です。

限界2

フィラートークンの効果はモデルやトークンの種類ごとにばらつきが大きく、背後にある正確なメカニズムはまだ解明されていません。

限界3

隠れた制約を満たす実験はClaude Opus 4.5の1事例であり、他のモデルにどこまで一般化するかは未確認です。

💡 R&Dでよく出る考え方
「モデルの出力に理由が書いてあるから安心」と考えたくなりますが、説明(CoT)と実際の計算が一致している保証はありません。安全性評価ではCoTの読解だけに頼らず、機械的解釈可能性モデル内部の重みや活性化を直接調べて、なぜその出力になったのかを解明しようとする研究分野など複数の手法を組み合わせる視点が重要です。
