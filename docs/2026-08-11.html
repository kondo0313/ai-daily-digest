Is Forward Prediction Enough? Physical State Grounding for JEPA World Models
Haodong Yan, Jiaguan Zhu ほか(共著16名) arXiv cs.RO (cross-list: cs.CV) ・ 2026年8月 原文 →

1「頭の中でシミュレーションする」ロボットの夢

ロボットが動く前に「もしこう動かしたら、次に何が起きるか」を頭の中で先読みできたら、失敗する前に計画を立て直せます。この「頭の中のシミュレーター」にあたるのが世界モデルエージェントが行動の結果を予測するための内部モデル。頭の中でシミュレーションする役割を持つです。近年は、生の画像そのものではなく抽象的な特徴空間で未来を予測するJEPAJoint-Embedding Predictive Architecture。画素ではなく特徴表現(潜在表現)の未来を予測する学習の枠組みという考え方が世界モデルの主流になりつつあります。

ただし、ここで新人研究者が見落としがちな問いがあります。「未来の予測がよく当たる」ことと、「その内部表現がロボットの物理的な状態を正しく捉えている」ことは、本当にイコールなのでしょうか。今日紹介する論文 PSG-JEPA は、この問いに正面から取り組み、シンプルな追加の学習目的だけで世界モデルの質を底上げしました。

2背景: 予測が当たっても「意味」が保証されるとは限らない

JEPA型の世界モデルは、観測を潜在表現生データを圧縮した内部的な特徴ベクトル。ニューラルネットの中間層の出力にあたるに変換するエンコーダーと、「今の潜在表現＋行動」から「次の潜在表現」を予測するプレディクタから成ります。学習は、予測した未来の潜在表現と実際の未来の潜在表現をできるだけ近づけるように行われます。

この学習方法はとても素直に見えますが、実は落とし穴があります。予測損失を下げること自体は、潜在表現が「ロボットの関節がどの角度にあるか」といった具体的な物理量を表している保証にはなりません。たとえるなら、模範解答のパターンを丸暗記して穴埋めテストで高得点を取る学生のようなもので、テストの点(予測精度)は良くても、中身を本当に理解している(＝物理状態を正しく表現できている)とは限らないのです。論文はこの性質を同定可能性ある内部表現から、元の物理量を一意に読み解いて復元できる性質。identifiabilityという言葉で呼び、これが低いままだと、その潜在表現を使ったプランニングや方策学習の質が頭打ちになると指摘します。

3手法: 予測損失に「物理への接地」を2つ追加する

そこで提案されたのが PSG-JEPA です。アイデアはシンプルで、通常の予測損失に加えて、学習時にだけ2つの「接地(グラウンディング)」目的を追加します。1つ目は個々の潜在表現を、ロボット自身が感じ取れる固有受容覚関節角度など自分の身体の状態を感じ取る感覚。プロプリオセプションの値に対応づける目的。2つ目は、離れた2つの時刻の潜在表現の「差」を、その間に実際に起きた関節角度の変化量に対応づける目的です。どちらも学習時にだけ働く補助的な損失で、推論時のネットワーク構造や計算コストはまったく変わらないというのが実用上のポイントです。

# 通常のJEPA学習: 現在の潜在表現から次の潜在表現を予測する
1z_t = encode(obs_t)
2z_next_pred = predictor(z_t, action_t)
# ① 予測損失: 予測した未来の潜在と実際の未来の潜在の誤差
3loss_pred = mse(z_next_pred, encode(obs_next))①
# ② 一点の接地: 潜在1つから関節角度を復元できるようにする
4state_hat = state_probe(z_t)
5loss_state = mse(state_hat, proprio_t)②
# ③ ペアの接地: 潜在の変化量を実際の関節角度の変化量に一致させる(複数先の時刻でも)
6delta_hat = delta_probe(z_t, z_future)
7loss_delta = mse(delta_hat, proprio_future - proprio_t)③
# 3つの損失を合算して最適化する。この処理は学習時だけで、推論時の構造・計算量は変わらない
8loss = loss_pred + loss_state + loss_delta
9backward(loss)

① 一点の接地: 「今の姿勢」を潜在から読み取れるようにする

1つ目の接地は、1つの潜在表現 z_t だけから、軽量な読み出し器(プローブ)でロボットの関節角度などの状態を予測できるようにする、というものです。これにより潜在表現は「予測に都合が良いだけの抽象的な符号」ではなく、「今ロボットがどんな姿勢にあるか」という具体的な情報を含んだものに近づきます。

② ペアの接地: 「潜在の変化」を「実際の身体の変化」に揃える

2つ目の接地は、ある時刻とその先の時刻(複数の時間幅で試す)の潜在表現の差分が、実際に起きた関節角度の変化量と対応するように学習させるものです。プランニングでは「この行動をとったら状態がどれだけ変わるか」を潜在空間の中で比較する場面が多いため、潜在の「変化の仕方」そのものを物理的な変化と揃えておくことは、下流のプランニングにとって理にかなっています。

4検証: 3段階で「本当に効いているか」を確かめる

PSG-JEPA の評価が丁寧なのも見どころです。(1) プロービングによる潜在の同定可能性そのものの検証、(2) 固定した潜在表現の上でのゴール条件付きプランニングの性能、(3) シミュレーションおよび実ロボットでの方策学習、という3つの階層すべてで、既存の最先端な潜在世界モデルの手法を上回ったと報告されています。

5なぜこの研究が重要か

世界モデル研究では、これまで「予測誤差をどれだけ下げられるか」が主な評価軸になりがちでした。PSG-JEPA は、予測精度という一つの指標だけを追いかけると、潜在表現が本当に使いたい物理的な意味を保証しないことを示し、それを補うための具体的でシンプルな処方箋(2つの接地損失)を提示した点に価値があります。しかも、この処方箋は学習時にだけ効くため、実運用のコストを上げずに恩恵を得られるという設計上のバランスの良さも、実務的な観点から見て学ぶところが多いです。

6意義と限界

前提

接地損失を計算するには、学習データに関節角度などの固有受容覚の正解値が必要になる。シミュレーションでは容易に得られるが、実ロボットでは正確なセンサー値の同期・キャリブレーションという追加の手間が生じうる。

対象

接地の対象は主に関節角度などのロボット自身の状態であり、接触力や柔らかい物体の変形といった、それ以外の物理量への一般化は今後の検討課題として残っていると考えられる。

適用範囲

評価はシミュレーションと実ロボットの双方で行われているが、扱うタスクやロボットの種類は限られており、より多様な身体・環境への汎化性は今後の検証が必要になる。

💡 R&Dでよく出る考え方
「損失関数を下げれば良いモデルになる」とは限りません。損失は目的を近似したものにすぎず、本当に欲しい性質(この論文では物理状態の同定可能性)は、それ専用の目的を明示的に足して初めて手に入ることが多いです。自分の研究でも「この指標さえ下がれば十分か？」と一度立ち止まって考えるくせをつけると、見落としを減らせます。
