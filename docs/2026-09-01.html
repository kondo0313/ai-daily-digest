SCALE: Self-uncertainty Conditioned Adaptive Looking and Execution for Vision-Language-Action Models
Hyeonbeom Choi, Daechul Ahn, Youhan Lee, Taewook Kang, Seongwon Cho, Jonghyun Choi arXiv cs.RO ・ 2026年2月投稿(2026年8月改訂) 原文 →

1自信がないとき、ロボットはどうすべきか?

ロボットアームが物をつかむ場面を想像してほしい。周囲が薄暗い、つかみたい物の一部が別の物に隠れている——そんなとき、人間なら思わず目を凝らして確認し直し、手つきも慎重になる。ところが今のロボット向けAIの多くは、この「迷ったら確認し直す」というごく当たり前の振る舞いを持っていない。今日紹介するのは、その振る舞いをたった1つの数式でロボットに実装した論文だ。

2VLAモデルと、テスト時スケーリングの限界

近年のロボット制御では、VLAモデルVision-Language-Action: カメラ画像と言語指示から、ロボットの関節角度やグリッパー開閉などの行動を直接出力するモデル が主流になりつつある。大量の操作データで学習しておき、「Aをつかんで B の上に置いて」のような指示と画像を入力するだけで、行動列を直接予測できるのが強みだ。

こうしたVLAをさらに賢くする方向性として、追加の学習をせず推論時の工夫だけで性能を底上げするtest-time scaling推論時に計算量を増やして性能を上げる手法。追加学習なしに精度を上げる代表的な戦略(TTS)が注目されている。しかし既存のTTS手法の多くは、追加の学習・別の検証モデル(verifier)・何度もやり直す複数回の推論を必要とし、リアルタイム制御が求められるロボットの現場では扱いにくい。さらに根本的な弱点として、これらの手法は「行動をどう決めるか」だけを調整し、「どう見るか」という視覚表現そのものは固定したままだった。だが霧がかった画像や物体の一部が隠れている場面のように、迷いの原因がそもそも「見え方」にあることは少なくない。

3SCALEの全体像:自己不確実性というたった1つの手がかり

SCALE は、VLAモデルが行動を1トークンずつ生成するたびに自然と得られる確率分布から「自分がどれだけ迷っているか」を計算し、その値1つで「見る」と「動く」の両方を同時に調整する。追加学習も外部の検証モデルも不要で、通常どおり1回だけ推論すれば完結する点が最大の特徴だ。

# 直前までの不確実性の変化から、今回どれだけ広く見るかを決める
1gamma = attention_temperature(delta_u_prev)
# その温度でカメラ画像を処理する(迷っているほど視野を広く)
2v = vision_encoder(obs, gamma)①
# 行動トークンを1つずつ生成しながら、その都度の迷いを測る
3for k in action_tokens:
4logits = policy(v, instruction, a_prev)
5u = self_uncertainty(logits)②
6tau = T0 * sigmoid(u)
7action[k] = sample(logits / tau)③
# 今回の不確実性を履歴に反映し、次ステップの“見る温度”に使う
8update_history(u)

① 「迷い」をどう数値化するか

SCALEはまず、モデルが出力する確率分布 p を2つの“ものさし”と比べる。1つは「完全に自信がある状態」——確率が1つのトークンに全部集中した分布。もう1つは「完全に迷っている状態」——全トークンに確率が均等に広がった分布だ。両者とのKLダイバージェンス2つの確率分布がどれだけ異なるかを測る指標の差を取ることで、「今の予測がどちらに近いか」を1つの数値 u として取り出す。u が大きいほど「迷っている」ことになる。

② 迷うほど大胆に、自信があるほど迷わず動く

この u を使って、行動を選ぶ際のサンプリング温度確率分布からどれだけランダムに選ぶかを決めるパラメータ。高いほど多様な選択肢を試し、低いほど最有力な答えに絞る τ を τ = T0・σ(u) と決める(σ はシグモイド関数)。迷っているときは温度を上げて色々な行動の可能性を試し、自信があるときは温度を下げてほぼ迷わず最有力な行動を選ぶ。

③ 迷うほど、もっと広く“見る”

もう一つの柱が、不確実性を“次にどう見るか”にも波及させる仕組みだ。直前までの不確実性の指数移動平均直近の値ほど重みを大きくして計算する平均。急な変化に素早く反応できるからの変化量Δuを使い、視覚エンコーダの注意の温度γを γ = κ^tanh(Δu) と変化させる。不確実性が急に上がった瞬間はγを大きくして画像のより広い範囲に注意を向け直し、下がってくれば注意を絞ってピンポイントに集中する。「行動で迷う→視野を広げて見直す→次の行動を決める」というフィードバックループが、追加学習なしに1回の推論の中で完結する。

着想は脳科学の“能動的推論”

この設計は、能動的推論Active Inference。生物は不確実性を減らすように知覚と行動の両方を調整しながら環境と関わる、という脳科学・認知科学の理論に着想を得ている。暗闇で物を探すとき、人は目を凝らし(知覚を変え)、同時に手探りで慎重に動く(行動を変える)。この日常的な振る舞いを、VLAモデルの推論プロセスにそのまま落とし込んだと言える。

6なぜ重要か

「何に迷っているか」ではなく「迷っている」という一点の情報だけで、見る力と動く力を同時に調整できる——それがSCALEの新規性だ。

従来のTTS手法は、行動の決め方だけを後から補正する“対症療法”に近かった。SCALEは、迷いの原因になりうる知覚そのものに手を伸ばし、しかも1回の推論で完結させることで、賢くなるための計算コストをほぼゼロに抑えている。理論的な裏付け(能動的推論)と実装のシンプルさを両立させている点が、単なるチューニング技巧と一線を画す。

7意義と限界

SCALEが示すのは、VLAモデルの頑健性向上に必ずしも追加学習や大きな計算コストは必要ない、という方向性だ。モデルが元々持っている出力分布の“形”を読み解くだけで、行動と知覚を同時に賢く調整できる。一方で、素直に受け止めるべき限界もある。

限界1

T0やκといったハイパーパラメータの調整が必要で、タスクやロボット構成が変わると再調整が要る可能性がある。

限界2

トークンレベルのKLダイバージェンスという“迷いの指標”が、ロボットが直面する本当に危険な状況を常に捉えられるとは限らない。

限界3

評価は主にピック&プレース系のマニピュレーションタスクが中心で、ヒューマノイドの全身制御のような、より複雑な行動への効果は今後の検証課題だろう。
